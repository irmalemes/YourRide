
# YourRide

YourRide is a team-based software engineering project developed as part of an Object-Oriented Analysis and Design (OOAD) course.

The project focuses on applying object-oriented principles, software design practices, and collaborative development to build an application.

## Project Overview

- **Project Type:** Academic team project
- **Focus:** Object-Oriented Analysis and Design
- **Key Areas:** Software Engineering, Application Development, Team Collaboration

## Software Engineering Practices

- Object-oriented analysis and design
- Application architecture and software design
- Collaborative development and version control

## Team Project

Developed collaboratively as part of university coursework at the Faculty of Electrical Engineering, University of Sarajevo.
